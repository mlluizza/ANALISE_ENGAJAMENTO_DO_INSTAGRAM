# ANÁLISE ENGAJAMENTO DO INSTAGRAM

### 1️⃣ Visão Geral do Projeto

### 📖 Visão Geral

- **Objetivo:**
  
  O projeto tem como objetivo analisar e obter insights sobre as métricas de engajamento no Instagram, com foco nos tipos de conteúdo, comentários, visualizações, tags, pessoas envolvidas, campanhas, carrosséis e interações. 
  O objetivo é entender os padrões de engajamento dos usuários e como diferentes fatores contribuem para o sucesso das postagens na plataforma.

 - **Principais Funcionalidades:**
  - ❤️ Coleta de dados das postagens do Instagram (Métricas de engajamento)
  - ❤️ Análise dos tipos de conteúdo, comentários, visualizações, tags, pessoas, campanhas
  - ❤️ Foco em Carrosséis e Padrões de Interações
  - ❤️ Visualização de Insights e Tendências
